---
name: student-research
description: Prepare an evidence-linked student risk briefing from the project's curated academic evidence.
---

Use the project root as the OpenClaw workspace and its Python environment. For a student risk or attendance research request, run the fixed command `python -m app.research.research_agent`. Read the returned evidence, comparisons and limitations. Cite the file IDs and distinguish synthetic labels from observed academic outcomes. If the topic falls outside the catalog, ask for relevant sources. Keep personal records out of the briefing.
